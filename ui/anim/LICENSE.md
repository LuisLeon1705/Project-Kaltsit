# Her 3D animations

VRM Animation (.vrma) files converted by [open-vrma](https://github.com/sanamiy/open-vrma)
(dataset: https://huggingface.co/datasets/Sanami/open-vrma), all **CC0 1.0** (public domain):

- `Idle_Loop`, `Idle_Talking_Loop`, `Walk_Loop`, `Walk_Formal_Loop`, `Sitting_Enter`,
  `Sitting_Idle_Loop`, `Sitting_Talking_Loop`, `Sitting_Exit`, `Idle_FoldArms_Loop`: Universal Animation Library 1 & 2 (Standard) by Quaternius — https://quaternius.com/
- `Waving`: KayKit Character Animations 1.1 by Kay Lousberg — https://kaylousberg.itch.io/kaykit-character-animations

No attribution is required; it is given here with thanks.
